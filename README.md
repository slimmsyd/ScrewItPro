# ScrewIt Pros

White-glove furniture assembly platform (marketing site + private-beta waitlist).

## App

The Next.js application lives in **[`my-app/`](./my-app/)**.

```bash
cd my-app
npm install
cp .env.example .env.local   # add API keys
npm run dev
```

Full setup, env vars, and architecture: **[my-app/README.md](./my-app/README.md)**.

## Stack

Next.js 16 · React 19 · Framer Motion · Google OAuth · Google Maps · Supabase / Stripe / Resend / DeepSeek clients (env-ready)

## Status

MVP marketing surface + waitlist + Chip concierge + Houston service-area map. See `my-app/README.md` for what works today vs what is env-stubbed.
